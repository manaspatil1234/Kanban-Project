# Kanban Task Manager

A simple and interactive Kanban board built using HTML, CSS, and JavaScript to organize and manage tasks visually.

## 🚀 Features

- **Task Management:** Organize tasks into different stages.
- **Kanban Board:** Manage tasks across To Do, In Progress, and Done columns.
- **Interactive UI:** A clean and user-friendly interface.
- **Drag and Drop:** Move tasks between columns.
- **Responsive Design:** Use the board across different screen sizes.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 💻 Getting Started

1. Clone this repository:
   ```bash
   git clone YOUR_REPOSITORY_URL
   ```
2. Open the project folder.
3. Open `Kanban.html` in your browser.

No additional dependencies are required for the basic version.
